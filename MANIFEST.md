# Manifesto do pacote Mindreader Trainer v2.1

Este ZIP reúne todos os componentes da versão atual da skill para OpenJarvis:

- `SKILL.md` — instruções completas, comandos e menu de ativação `/mente`.
- `README.md` — instalação e uso.
- `QUICK_START.txt` — guia rápido.
- `CLAUDE_INSTALL_PROMPT.md` — prompt completo para Claude revisar, instalar e testar no Jarvis.
- `VERSION` — versão do pacote.
- `SOURCE_NOTES.md` — notas de origem e organização.
- `references/BOOK_MAP.md` — mapa curricular pelos 20 capítulos.
- `references/TECHNIQUE_CATALOG.md` — catálogo granular de técnicas/padrões.
- `references/TRAINING_ENGINE.md` — regras para geração e condução dos exercícios.
- `references/SCORING.md` — rubricas de avaliação.
- `references/SAFETY_AND_EVIDENCE.md` — limites de inferência e evidência.
- `assets/flashcards.jsonl` — banco de flashcards.
- `assets/scenario_blueprints.json` — modelos de cenários.
- `examples/SESSION_EXAMPLES.md` — exemplos de uso.
- `examples/progress-example.json` — exemplo de progresso.
- `scripts/progress.py` — persistência local opcional.
- `install.sh` — instalador Linux/macOS com backup.
- `install.ps1` — instalador Windows com backup.

O PDF original do livro não está incluído no pacote.
