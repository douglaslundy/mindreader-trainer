# Catálogo operacional de técnicas

Formato: técnica → observar → perguntar/testar → não concluir automaticamente.

1. Pronome de primeira pessoa → participação/compromisso linguístico → comparar padrão habitual → não equivale a sinceridade.
2. Omissão de pronome → possível distanciamento → pedir formulação específica → não equivale a culpa.
3. Voz ativa/passiva → agência expressa → “quem fez o quê?” → estilo gramatical pode explicar.
4. Proximidade demonstrativa → este/aqui vs esse/aí → comparar mudanças → não usar isoladamente.
5. Eufemismo → redução de impacto → “qual termo concreto descreve isso?” → pode ser mera polidez.
6. Simplicidade emocional → emoção intensa tende a linguagem direta segundo o autor → comparar timing/contexto → não autentica trauma.
7. Nós/nosso → afiliação → observar padrão no tempo → pode ser hábito cultural.
8. Ordem de menção → saliência/prioridade possível → pedir exploração espontânea → ordem convencional pode explicar.
9. Omissão saliente → tema possivelmente evitado → perguntar de modo neutro → ausência não prova interesse oculto.
10. Representação simbólica → tratamento de objetos associados → buscar contexto → não inferir sentimento definitivo.
11. Palavras funcionais → perspectiva compartilhada → comparar reciprocidade → não confundir fluência com afeto.
12. Holofotes conversacionais → intenção de envolver/ênfase → interpretar pelo contexto → em contexto defensivo podem significar outra coisa.
13. Suavização de pedido → percepção de poder/status → contar mecanismos combinados → polidez cultural é confounder.
14. Pouco esforço para obter cooperação → poder percebido → observar várias interações → medo não é respeito.
15. Foco interno/externo → insegurança/status possível → comparar com linha de base → não usar como traço único.
16. Linha de base → padrão pessoal neutro → comparar tema sensível vs neutro → não comparar com estereótipos universais.
17. Qualificador → incerteza subjetiva → “o que faria você ter certeza?” → pode ser precisão epistêmica saudável.
18. Retrator → hesitação/saída discursiva → explorar o “mas” → não equivale a ansiedade clínica.
19. Pronome mim/me → sensação de passividade/vitimização possível → buscar agência → estrutura sintática pode exigir.
20. Mudança para você/eles → hostilidade/distância possível → comparar antes/depois → não prova raiva.
21. Linguagem concreta sob raiva → necessidade de precisão/controle → checar estado → pode ser estilo direto.
22. Autonarração → abertura/cooperatividade possível → observar naturalidade → pode ser hábito.
23. Barreira física → desconforto possível → checar ambiente → frio, postura e ergonomia confundem.
24. Fator de estresse indireto → reação a tema → usar como exploratório → reação não prova culpa.
25. Negação direta → qualidade de resposta → distinguir “não fiz” de moralização → pessoas inocentes também podem reagir mal.
26. Responder pergunta com pergunta → atraso/evasão possível → repetir pergunta específica → pode ser clarificação legítima.
27. “Por que eu mentiria?” → deslocamento do ato para motivação → voltar ao fato → não é prova.
28. Discurso filosófico → possível justificação → trazer de volta ao evento → pode ser estilo retórico.
29. Autorreferência (“como já disse”) → economia cognitiva possível → pedir reconstrução independente → pode ser organização normal.
30. Complexidade sintática → distinções e exceções → analisar clareza, não tamanho de palavras → não usar como detector isolado.
31. Alívio após tema → desconforto com assunto → retomar mais tarde → inocentes também sentem alívio.
32. Gestão de impressão → esforço para parecer “certo” → perguntar por fatos e custos → autopresentação é universal.
33. Excesso de compensação → ênfase desproporcional → comparar incentivo → personalidade expressiva pode explicar.
34. Ameaça legítima vs blefe → custo/preparação/alternativas → “o que fará concretamente?” → ausência de preparação não zera risco.
35. Relevância de detalhes → quanto contribuem ao evento → pedir elementos verificáveis → detalhe irrelevante pode ser memória espontânea.
36. Proporção narrativa → abertura/meio/consequência → comparar equilíbrio → trauma altera sequência.
37. Integração de detalhes → se estão encaixados em ação/contexto → pedir transições → ensaio também pode ser coerente.
38. Detalhe vívido → espaço/tempo/ação → verificar externamente → imaginação também produz vividez.
39. Multissensorialidade → vários sentidos incorporados → checar espontaneidade → não é prova.
40. Perspectiva de terceiros → representação de outra mente/fala → verificar testemunha → pode ser inventada.
41. Transição de cena → continuidade episódica → “o que ocorreu entre A e B?” → lacunas de memória são normais.
42. Contratempo embutido → imprevisto secundário → buscar verificabilidade → pode ser adornamento.
43. Encerramento abrupto → desejo de terminar → pedir consequências → cansaço/estresse também explicam.
44. Precisão improvável → memória “perfeita” distante → pedir fonte de lembrança → registros podem sustentar precisão.
45. Detalhes verificáveis → locais, pagamentos, mensagens, pessoas → checar independente → ferramenta de maior valor prático.
46. Cronologia → antes/durante/depois → construir linha temporal → relógio humano é impreciso.
47. Evidência estratégica → obter versão antes de revelar dado conhecido → comparar discrepâncias → preservar fairness.
48. Autoridade → título/roupa/documento → verificação independente → autoridade real ainda pode errar.
49. Confusão → sobrecarga emocional → desacelerar → urgência real às vezes existe.
50. Credibilidade por fatos verdadeiros → dois fatos usados para “colar” mentira → verificar o próximo elo → conhecimento não implica legitimidade.
51. História persuasiva → Sistema 1 → separar alegação de evidência → narrativa boa pode ser verdadeira.
52. Similaridade → “eu também” → checar autenticidade e timing → afinidade genuína existe.
53. Bajulação → julgamento contaminado → adiar decisão → elogio sincero existe.
54. Reciprocidade → dívida psicológica → separar presente de obrigação → reciprocidade também é norma social saudável.
55. Custo irrecuperável → investimento passado prendendo decisão → “eu escolheria isso hoje do zero?” → custos de saída podem ser reais.
56. Revelação precoce → intimidade acelerada → checar pressão por reciprocidade → algumas pessoas são naturalmente abertas.
57. Estado vs traço → frequência/duração/intensidade/contexto → procurar padrão → nunca inferir traço de episódio isolado.
58. Dominante/submisso → direção típica de ansiedade → observar múltiplos contextos → não são diagnósticos.
59. Humor × status → desvio da resposta esperada → usar matriz → contexto cultural importa.
60. Conector vs confrontador → linguagem que suaviza vs impõe → comparar status → assertividade saudável não é hostilidade.
61. Positividade/negatividade → temas lexicais → observar padrão → temperamento e contexto.
62. Metáforas → modelo mental implícito → perguntar “o que isso significa para você?” → metáfora pode ser casual.
63. Viés de confirmação → buscar apenas apoio → obrigar hipótese rival → ferramenta de debiasing.
64. Representatividade → encaixar pessoa em categoria → pedir evidência individual → estatística não é destino.
65. Narrativa de identidade → história do “eu” → perguntar papel, causa, padrão → não prever com certeza.
66. Agência → “o que estava sob seu controle?” → distinguir causa interna/externa → fatores externos podem ser reais.
67. Dissonância → conflito entre autoimagem e fato → observar racionalização → desconforto não prova falsidade.
68. Nervo exposto → reação desproporcional a área identitária → investigar sem acusar → trauma/contexto podem explicar.
69. Dissociação linguística → impessoalização de experiência → checar dor/intimidade → não diagnosticar dissociação clínica.
70. Cinco domínios de valor → caráter/relacionamentos/posses/físico/profissão → observar ênfase → nenhum domínio é “melhor”.
71. Elogio espontâneo → revela o que chama atenção → comparar com escolhas → elogio social pode ser convencional.
72. Hipersensibilidade de valor → tema repetidamente projetado → buscar insegurança alternativa → não concluir carência específica.
73. Valor sob custo → escolha quando prioridades conflitam → analisar repetição → necessidade pode limitar escolha.
74. Significado vs gratificação → longo prazo vs impulso → observar autocontrole → não moralizar lazer.
75. Resiliência → recuperação e adaptação → medir após revés → reação inicial não basta.
76. Excesso/ausência → virtude em extremos pode virar problema → buscar meio funcional → contexto define ótimo.
77. Contaminação narrativa → positivo vira negativo → perguntar exceções → estilo pessimista não é diagnóstico.
78. Redenção narrativa → adversidade integrada em crescimento → verificar realidade → positividade forçada existe.
79. Absolutismos → sempre/nunca/todo mundo → testar exceções → linguagem figurada é comum.
80. Intensificadores → 100%, absolutamente → buscar embasamento → ênfase cultural existe.
81. Autoestima vs confiança → valor pessoal vs competência situacional → perguntar separadamente → não inferir autoestima de performance.
82. Ego compensatório → exibição para sustentar autoimagem → buscar padrão de comparação → sucesso legítimo não é patologia.
83. História relacional → duração/qualidade/repetição → perguntar por papel próprio → relações ruins podem refletir ambiente.
84. Duas caras por status → cordial acima, hostil abaixo → comparar tratamento de quem não oferece benefício → um episódio não basta.
85. Fronteira/limite → resposta a “não” e espaço alheio → observar repetição → desconhecimento cultural pode explicar.
86. Capacidade de pedir ajuda → equilíbrio entre autonomia e conexão → observar forma do pedido → reserva não é doença.
87. Foco negativo/ruminação → atenção presa em ameaça → checar duração e prejuízo → não diagnosticar depressão.
88. Imediatismo temporal → predomínio do presente → procurar contexto → estilo linguístico varia.
89. Motorista vs passageiro → linguagem de agência vs sujeição → perguntar escolha possível → reconhecer restrições reais.
90. Escalada de risco → ameaça, preparação, acesso, repetição, deterioração → priorizar segurança → doença mental não equivale a violência.
